# Pengajuan Sales (uji coba)

Salinan tab **Pengajuan sales** dari Dashboard Penjualan PT Svarna Dipa. Dibuat supaya bot bisa diuji
tanpa menunggu jalur Mac. Alurnya: **sales mengajukan → pusat (Ibu / Bu Diana) ACC → bot di PC menulis ke
Accurate dalam ±5 detik → status di halaman berubah jadi Selesai atau Gagal.**

```
cabang (sales/admin)  ──ajukan──►  penyimpan Apps Script  ◄──ACC──  pusat (Ibu / Bu Diana)
                                          ▲      │
                                 status   │      │ dibaca tiap 5 detik
                                          │      ▼
                                   bot/eksekutor_pengajuan.py  ──►  Accurate Online
```

## Isi repo

| Berkas | Fungsi |
|---|---|
| `index.html`, `pusat/`, `jakarta/` … `makassar/` | Halaman bersandi. Sandinya sama dengan Dashboard-Svarna. Data Accurate di `data.json` terkunci AES-GCM. |
| `web/shim.js` | Menghubungkan halaman ke penyimpan Apps Script. Kode tab pengajuan tidak diubah. |
| `apps_script/Kode.gs` | Penyimpan. Satu koleksi pengajuan untuk semua cabang. Cabang **tidak bisa** memberi ACC; ini dicek di server. |
| `bot/eksekutor_pengajuan.py` | Bot ACC → Accurate. |
| `skrip/bangun.py` | Membangun ulang halaman dari data dashboard terbaru, lalu `--kirim` ke GitHub. |

Repo ini **tidak berisi** token, sandi, kunci, data mentah, maupun log.
