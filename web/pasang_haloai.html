Pasang “Isi dari Gio” untuk HaloAI

Sekali saja per komputer. Gunanya: saat tombol 📤 HaloAI di dashboard Tagih WA diklik, chat toko dan pesannya terisi sendiri di HaloAI.

Langkah 1 — munculkan bilah bookmark
  1. Windows: tekan Ctrl + Shift + B
  2. MacBook: tekan Cmd + Shift + B

Bilah tipis muncul tepat di bawah kotak alamat Chrome.

Langkah 2 — SERET tombol hijau ini ke bilah bookmark

⭐ Isi dari Gio (HaloAI)

Tahan klik kiri pada tombol, geser ke bilah bookmark, lalu lepaskan. Jangan diklik di halaman ini.

Cara pakai sehari-hari
  1. Di dashboard Tagih via WA, klik 📤 HaloAI pada toko yang mau ditagih.
  2. Tab HaloAI terbuka. Klik bookmark ⭐ Isi dari Gio di bilah bookmark.
  3. Chat toko terbuka dan pesannya terisi. Kalau komputer ini punya Pembantu Gio, klik kotak chat lalu Ctrl+V (Mac: Cmd+V) untuk menempel PDF rincian dan foto nota.
  4. Periksa nama toko di chat, lalu tekan Kirim.

Komputer lain di kantor perlu memasang ini sendiri-sendiri. Sudah pernah memasang? Tidak perlu diulang.
